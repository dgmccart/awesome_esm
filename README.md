# Awesome ESM

A curated collection of resources, papers, tutorials, and community examples for the ESM family of protein language models.

## Quick Links

- **Website:** [awesome-esm.github.io](https://awesome-esm.github.io)
- **ESM GitHub:** [github.com/Biohub/esm](https://github.com/Biohub/esm)
- **Biohub:** [biohub.ai](https://biohub.ai)
- **Tutorials:** [biohub.ai/resources/tutorials](https://biohub.ai/resources/tutorials)

## Contributing

We welcome contributions! See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines and templates.

### Ways to Contribute

- **Add a paper:** [Use this template](https://github.com/Biohub/awesome-esm/issues/new?template=add-paper.md)
- **Share a use case:** [Use this template](https://github.com/Biohub/awesome-esm/issues/new?template=add-use-case.md)
- **Suggest a FAQ entry:** [Use this template](https://github.com/Biohub/awesome-esm/issues/new?template=add-faq.md)
- **Request or contribute a tutorial:** [Use this template](https://github.com/Biohub/awesome-esm/issues/new?template=tutorial-request.md)
