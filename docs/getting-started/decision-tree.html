1. What’s your primary goal?

2A. Sequence Representations & Embeddings

What’s your use case?

I’m doing research and want the best representations → Use ESMC (latest, best quality, metagenomic training) - Model Card - Tutorial: Getting Embeddings - GitHub

I have existing ESM2 code and want to upgrade → Use ESMC (drop-in replacement, but see migration guide) - Migration Guide - Comparison Table

I’m using legacy code tied to ESM2 → Stay with ESM2 (for now) - ESM2 Docs - Plan migration to ESMC when ready

I want to fine-tune on my own data → Use ESMC - Fine-tuning Tutorial - Larger models (6B) work best, but 300M is faster for experiments

I need this to be very fast → Use ESMC-300M - Smallest model, still high quality - Much faster inference than larger models

2B. Protein Design & Generation

What do you want to design?

De novo proteins (completely new sequences) → Use ESM3 - Model Card - Design Tutorial - Paper

Protein binders (antibodies, miniproteins) → Use ESM3 with ESMFold2 - Generate sequences with ESM3 - Validate structures with ESMFold2 - Binder Design Example

Enzyme variants (improving existing proteins) → Use ESMC + ESMFold2 - Score mutations with ESMC embeddings - Validate with structure prediction - Directed Evolution Example

2C. Structure Prediction

What type of structure do you need?

Single protein chain (monomers) → Use ESMFold2-Fast - Fastest option - Excellent accuracy - Tutorial

Protein complexes (antibody-antigen, PPIs, multimers) → Use ESMFold2 - State-of-the-art accuracy - Handles up to 768 residues (all chains combined) - Complex Prediction Tutorial

Large complexes (>768 residues) → Use ESMFold2-Fast on individual chains, then dock manually - Or use Docking Tools - Future versions may support longer sequences

I need maximum accuracy → Use ESMFold2 with MSA - Request on Biohub - 3-5% better accuracy with multiple sequence alignment

I need to screen thousands of structures quickly → Use ESMFold2-Fast - 1.3x faster than ESMFold2 - Minimal accuracy trade-off

2D. Mutation Scoring & Variant Effects

What’s your goal?

Predict effects of all possible mutations (variant effect prediction) → Use ESMC with log-likelihood ratios - Mutation Scoring Tutorial - Variant Prediction Example

Find stabilizing mutations for protein engineering → Use ESMC + ESMFold2 - Score with ESMC - Validate stability with structure - Stability Engineering Example

Understand disease-causing mutations → Use ESMC - Disease Prediction Tutorial - Compare wild-type vs. mutant log-likelihood

Protein function prediction → Use ESMC - Function information in layer 50-60 - Function Prediction Example
