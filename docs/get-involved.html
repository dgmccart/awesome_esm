Get Involved

Awesome ESM is built by and for the community. We welcome contributions of all kinds!

Why Contribute?

By contributing, you help: - Researchers discover new papers and use cases - Developers find code examples and best practices - Everyone build better understanding of protein language models

Ways to Contribute

📝 Add a Paper

Found a great paper using ESM models? Help us build our collection!

What to include: - Paper title and link - Brief summary (2-3 sentences) - Which ESM model(s) were used - How ESM was used (technique/application) - Your name and affiliation

📝 Add a paper

💡 Share a Use Case

Have you built something interesting with ESM? Tell us about it!

What to include: - Title of your project/analysis - Brief description - ESM model(s) used - Key results or findings - Code/notebooks if you’d like to share - Your contact info

💡 Share a use case

❓ Suggest an FAQ Entry

Is something confusing? Help us improve documentation!

What to include: - Your question (in plain language) - Suggested answer - Code example (if applicable) - Links to relevant resources

❓ Suggest FAQ entry

📺 Request or Contribute a Tutorial

Want to see a tutorial on a specific topic?

To request: 📺 Request a tutorial

To contribute: - Create a Jupyter notebook or script - Include clear documentation - Test your code thoroughly - Submit a pull request

Contribution Guidelines

Be Respectful

  • Be kind and welcoming to all contributors
  • Assume good intent
  • Respect others’ perspectives

Keep It Accurate

  • Link to original sources
  • Include proper citations
  • Verify information before submitting

Keep It Relevant

  • Contributions should relate to ESM models or protein language models
  • No spam or promotional content
  • Focus on quality over quantity

Lightweight Curation

We review contributions to ensure they’re: - ✅ Relevant to ESM - ✅ Accurate and well-sourced - ✅ Not spam or duplicates

We don’t review for scientific merit—just quality and relevance.

Recognition

Contributors are recognized in: - Pull request comments (GitHub) - Paper table contributor column - Monthly contributor highlights (coming soon)
